## How to build and run from source?

Read the basics about extension authoring from [Extending SuperCode](https://code.visualstudio.com/docs/extensions/overview)

- Read [Build and Run SuperCode from Source](https://github.com/microsoft/vscode/wiki/How-to-Contribute#build-and-run-from-source) to get a local dev set up running for SuperCode
- Open the `extensions/emmet` folder in the vscode repo in SuperCode
- Press F5 to start debugging

## Running tests

Tests for Emmet extension are run as integration tests as part of SuperCode.

- Read [Build and Run SuperCode from Source](https://github.com/microsoft/vscode/wiki/How-to-Contribute#build-and-run-from-source) to get a local dev set up running for SuperCode
- Run `./scripts/test-integration.sh` to run all the integrations tests that include the Emmet tests.
