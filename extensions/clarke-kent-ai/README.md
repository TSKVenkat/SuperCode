# Clarke Kent AI Assistant

Your Superman-powered AI coding assistant for SuperCode IDE.

## Features

- **Prompt-to-Code Generation**: Describe what you want, get working code
- **Multi-Model Support**: Access GPT-4, Claude, Llama, and 100+ models via OpenRouter
- **Smart Model Routing**: Automatically selects the best model for each task
- **Real-Time Editing**: Iterative code refinement with AI assistance
- **Debugging Assistance**: AI-powered error analysis and fix suggestions
- **Full-Stack Generation**: Generate complete project structures

## Commands

- `Clarke Kent: Open Chat` - Open the chat panel
- `Clarke Kent: Generate Code from Prompt` - Generate code from a description
- `Clarke Kent: Refine Selection` - Improve selected code
- `Clarke Kent: Explain Code` - Get an explanation of selected code
- `Clarke Kent: Analyze Error` - Get help with an error
- `Clarke Kent: Generate Full Project` - Create a complete project structure

## Keyboard Shortcuts

- `Ctrl+Shift+K` / `Cmd+Shift+K` - Open Chat
- `Ctrl+Shift+G` / `Cmd+Shift+G` - Generate Code
- `Ctrl+Shift+R` / `Cmd+Shift+R` - Refine Selection

## Configuration

Set your OpenRouter API key:
1. Open Command Palette (`Ctrl+Shift+P`)
2. Run "Clarke Kent: Set API Key"
3. Enter your OpenRouter API key
